# FuelIQ AI User Flow

1. User enters FuelIQ

↓

2. User uploads CSV or Excel dataset

↓

3. Validation Engine checks:
   - Missing values
   - Duplicates
   - Outliers

↓

4. User receives Data Quality Report

↓

5. Analytics Engine processes dataset

↓

6. Prediction Engine generates:
   - CO₂ Emission Predictions
   - Fuel Consumption Insights

↓

7. Sustainability Engine calculates score

↓

8. Risk Engine classifies:
   - Low Risk
   - Medium Risk
   - High Risk

↓

9. Recommendation Engine generates suggestions

↓

10. Dashboard displays results

↓

11. User exports report
